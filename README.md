# Broadcasts

Watch multiple broadcasts on one screen.

## Live

- [Cloudflare Pages](https://broadcastsapp.pages.dev/)
- [GitHub Pages](https://itwasallcode.github.io/broadcasts/)

## Features

- Watch multiple streams side by side with several grid layouts.
- Create personal playlists and organize your streams.
- Keep playlists and layout preferences saved in your browser.
- Import and export playlists.

## Platforms

- `YouTube`

## Install

The app can be installed as a PWA:

- **Desktop (Chrome, Edge, Brave):** Click the install icon at the right end of the address bar.
- **iOS (Safari):** Select `Share` → `Add to Home Screen`, enable `Open as Web App` if shown, then select `Add`.
