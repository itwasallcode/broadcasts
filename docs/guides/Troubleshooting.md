# Troubleshooting

## Streams

- `Stream did not load`: select `Retry`.
- For unavailable videos, use the home icon to find the channel's current live stream.
- To edit a personal stream's URL, select its name in the menu.
- For broken default streams, [open an issue](https://github.com/itwasallcode/broadcasts/issues) with the stream name and a replacement URL if known.

## App Updates

- In the menu, select `Check for Updates`, then `Update and Reload` if available.
- If a check or update fails, try another network and select `Retry`.
- Updates keep saved playlists and preferences.
- On older versions without an update button, close all app tabs and windows, then reopen.

## Saved Preferences

- Preferences stay in this browser; `Cloudflare Pages` and `GitHub Pages` store them separately.
- Use `Export` and `Import` in the gear menu to transfer playlists without replacing existing ones.
- Each export contains one playlist and its streams, without grid preferences.
- `Changes Not Saved`: retry saving or export affected playlists before closing or reloading.
- Clearing site data deletes saved playlists and preferences, so export your playlists first.

## Fullscreen

- The `Fullscreen` button requires browser support and a mouse or trackpad.
