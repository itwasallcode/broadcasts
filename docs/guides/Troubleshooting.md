# Troubleshooting

- If a stream shows `Stream did not load`, select `Retry` to reload it.
- If the app looks outdated, open the menu and select `Check for Updates`, then select `Update and Reload` when an update is ready.
- If a check or update fails, restore your connection and select `Retry` on the same button.
- Updates preserve saved layouts, stream order and custom streams on the same site address.
- If an older version has no update button, close all of its tabs and installed app windows to let the new version activate, then open the app again.
- There is no fullscreen button on phones — it only appears on devices with a mouse.
